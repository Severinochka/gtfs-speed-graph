# Разработка методов построения транспортных графов по GTFS-данным и прогнозирования скоростных характеристик движения на новых сетях

## Актуальность
Стандартом де-факто для публикации данных общественного транспорта является спецификация GTFS. Однако доступность данных сильно ограничена: GTFS Static публикуют около 30% крупных российских городов, а GTFS Realtime — менее 5%. Это значит, что для большинства городов доступны только плановые (декларируемые) расписания, которые не отражают реальную динамику движения — заторы, погодные условия, ДТП и другие факторы.

Особенно остро эта проблема стоит для новых маршрутных сетей и проектируемых районов («проблема холодного старта»): для них исторических данных о движении (GPS-треков) попросту не существует. Классические решения — покупка коммерческих Floating Car Data или ручная нормативная параметризация графа — требуют либо больших финансовых затрат, либо огромных трудозатрат инженеров.

Разработка метода, который позволяет прогнозировать скоростные характеристики на основе доступных открытых данных (GTFS + OpenStreetMap) без привлечения коммерческих данных, — актуальная научно-практическая задача.
## Цель работы
Повышение точности и снижение ресурсоемкости транспортных моделей новых маршрутных сетей за счёт разработки метода построения графа с прогнозируемыми скоростными весами рёбер на основе открытых данных.
## Задачи
1. Проанализировать предметную область и выявить ограничения текущих форматов данных (GTFS Static, GTFS-RT) для задач транспортного моделирования.
2. Провести системный анализ процесса подготовки данных и выявить наиболее трудоёмкие и рискованные этапы.
3. Сравнить существующие методы расчёта скоростей (нормативный метод, FCD) по экономической эффективности.
4. Сформулировать гипотезу и разработать концепцию метода автоматизированной параметризации транспортного графа для новых сетей.
5. Подготовить и систематизировать датасет на примере транспортной сети Санкт-Петербурга для последующих экспериментов.
## Методы и технологии
- Системный анализ и BPMN-моделирование бизнес-процессов
- Анализ реляционных данных: SQL, PostGIS
- Геоинформационный анализ: QGIS
- Машинное обучение: градиентный бустинг, случайные леса
- Сравнительный экономический анализ (CAPEX/OPEX)
## Планируемые результаты
Метод построения параметризованного транспортного графа для новых маршрутных сетей (Greenfield projects), основанный на совместном анализе открытых данных GTFS и инфраструктурных признаков OSM с применением ML — без использования коммерческих GPS-данных. Ожидаемая точность прогноза (по MAPE) — средняя/высокая, при кратно меньших затратах по сравнению с нормативным методом и закупкой FCD. Решение масштабируемо на любой город РФ, публикующий GTFS-данные.
